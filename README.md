# Aniversário Helena

Landing page mobile-first inspirada no meme clássico da Hebe para o aniversário da Helena.

## Funcionalidades do MVP

- tela inicial com boas-vindas e identidade visual divertida
- player responsivo do vídeo do meme
- replay ilimitado
- gerador de figurinha com upload de foto
- exportação em PNG e WEBP
- galeria de fotos do evento
- ranking de figurinhas
- compartilhamento com Web Share API e cópia de link

## Como executar localmente

```bash
python3 -m http.server 8000
```

Depois abra:

```text
http://localhost:8000/
```

## Publicação

Este projeto pode ser publicado diretamente no GitHub Pages com a branch `main` ou via GitHub Actions.

## Arquivos principais

- `index.html` - estrutura da página
- `styles.css` - design e responsividade mobile
- `script.js` - interações e geração da figurinha
